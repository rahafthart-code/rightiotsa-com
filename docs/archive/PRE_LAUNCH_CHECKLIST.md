## 9. السيناريوهات التجارية 🎭

### سيناريو 1: العميل الجديد
```
1. يزور الموقع → يرى "إدارة احترافية للأصول الحيوانية"
2. يضغط "الباقات" → يقارن الأسعار
3. يختار "باقة الخيل" → يضغط "اشترك الآن"
4. يوافق على الشروط → يدفع بالبطاقة
5. ينتقل للوحة التحكم → يرى الخريطة بالعربية
```

### سيناريو 2: طلب عرض مخصص
```
1. يزور الموقع → يضغط "اطلب عرضًا مخصصًا"
2. يملأ النموذج: 10 جمال، منطقة حائل
3. يضغط "إرسال" → يرى رسالة تأكيد
4. يضغط واتساب → يتواصل مباشرة
```

### سيناريو 3: استخدام اللوحة
```

2. يختار "خزامة" (الناقة) → يرى موقعها على الخريطة
3. يختار "عنتر" (الحصان) → يرى نبض القلب 85
4. يضغط "الأقمار الصناعية" → يتبدل للعرض العادي
```
